# crud-bootstrap-php-main2.0

## Sobre o projeto

Aplicação PHP de cadastro de clientes, com páginas para listar, adicionar, editar, visualizar e excluir registros. A interface inclui Bootstrap e arquivos de conexão ao banco.

## Como explorar

Use um servidor PHP de desenvolvimento. Revise os arquivos de conexão ao banco e identifique o esquema necessário antes de abrir `index.php`. A versão mínima de PHP e a criação do banco não estão documentadas na raiz.
